维度单一，菜品信息缺失

MCP Skills
核心 MCP Tools 设计
标准化 MCP 接口，让任何 AI Agent 都能调用的美食智能服务
01

按评价语义搜菜品

search_dish_by_semantic_review

基于自然语言描述，在指定城市中搜索匹配的菜品及UP主评价原文。

示例查询 "北京，红烧肉要肥而不腻，有UP主认证过的"
02

获取餐厅深度点评

get_restaurant_detailed_review

汇总所有探访过该店的UP主名单，及各道菜品的好评/差评统计清单。

示例查询 "四季民福烤鸭店的所有UP主评价汇总"
03

生成美食打卡路线

generate_food_tour_itinerary

结合地理位置与UP主评价偏好，生成结构化的多日美食行程表。

示例查询 "跟着老饭骨口味走的北京两天一夜高性价比路线"
